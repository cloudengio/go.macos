# [cloudeng.io/macos/cmd/cloudeng-aws-secrets](https://pkg.go.dev/cloudeng.io/macos/cmd/cloudeng-aws-secrets?tab=doc)


Usage of `cloudeng-aws-secrets`

    provide access to aws secretsmanager on macos with aws credentials stored in the
    keychain

     read - read a secret from aws secretsmanager writing it to filename, if filename is - the secret will be written to stdout
    write - write a secret read from <filename>, to aws secretsmanager, if filename is - the secret will be read from stdin
